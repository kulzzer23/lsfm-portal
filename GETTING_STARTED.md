# Руководство по запуску проекта Los-Santos FM

## Шаг 1: Установка Node.js

Перед началом работы вам нужно установить Node.js (который включает npm).

### Для Windows:

1. Перейдите на сайт: https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуется)
3. Запустите установщик и следуйте инструкциям
4. После установки **перезапустите VS Code** или командную строку

### Проверка установки:

Откройте командную строку (cmd) или терминал в VS Code и введите:

```bash
node --version
npm --version
```

Если видите версии (например, v20.x.x и 10.x.x) - всё установлено правильно!

## Шаг 2: Установка зависимостей проекта

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Это установит все необходимые пакеты (Vite и Supabase). Процесс займёт 1-2 минуты.

После установки появится папка `node_modules/` с зависимостями.

## Шаг 3: Запуск локального сервера разработки

Выполните команду:

```bash
npm run dev
```

Вы увидите сообщение вроде:

```
  VITE v5.0.0  ready in 500 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
  ➜  press h to show help
```

Браузер автоматически откроется на `http://localhost:3000` и вы увидите сайт!

### Полезные команды при разработке:

- **npm run dev** - запустить dev-сервер (с горячей перезагрузкой)
- **npm run build** - собрать проект для продакшена
- **npm run preview** - просмотреть собранный проект

## Шаг 4: Работа с сайтом

Пока работает `npm run dev`:

1. Открывайте файлы в VS Code и редактируйте
2. Сохраняйте изменения (Ctrl+S)
3. Браузер автоматически обновится с новыми изменениями!

Чтобы остановить сервер: нажмите **Ctrl+C** в терминале.

## Шаг 5: Загрузка проекта на GitHub

### 5.1. Создайте репозиторий на GitHub

1. Зайдите на https://github.com
2. Нажмите кнопку **"New repository"** (или "+")
3. Введите название: `lsfm-portal` (или любое другое)
4. **НЕ** добавляйте README, .gitignore или лицензию (они уже есть в проекте)
5. Нажмите **"Create repository"**

### 5.2. Инициализируйте Git в проекте

Откройте терминал в папке проекта и выполните:

```bash
git init
```

### 5.3. Добавьте все файлы в Git

```bash
git add .
```

Проверьте что добавилось:

```bash
git status
```

### 5.4. Создайте первый коммит

```bash
git commit -m "Initial commit: Los-Santos FM portal"
```

### 5.5. Подключите удалённый репозиторий

Замените `YOUR_USERNAME` и `YOUR_REPO` на ваши данные:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
```

Например:
```bash
git remote add origin https://github.com/kulzzer23/lsfm-portal.git
```

### 5.6. Отправьте код на GitHub

```bash
git branch -M main
git push -u origin main
```

Если GitHub попросит авторизацию:
- Введите ваш логин
- Вместо пароля используйте **Personal Access Token** (создаётся в Settings → Developer settings → Personal access tokens)

## Шаг 6: Настройка автоматического деплоя на GitHub Pages

После загрузки кода на GitHub:

1. Перейдите в ваш репозиторий на GitHub
2. Откройте **Settings** (настройки)
3. В левом меню найдите **Pages**
4. В разделе **Source** выберите **"GitHub Actions"**
5. Готово! Теперь при каждом push сайт будет автоматически обновляться

Первый деплой запустится автоматически. Следите за процессом во вкладке **Actions**.

После успешного деплоя ваш сайт будет доступен по адресу:
```
https://YOUR_USERNAME.github.io/YOUR_REPO/
```

## Шаг 7: Дальнейшая работа с Git

### Сохранение изменений:

После редактирования файлов:

```bash
# Посмотреть что изменилось
git status

# Добавить изменённые файлы
git add .

# Или добавить конкретный файл
git add src/main.js

# Создать коммит с описанием
git commit -m "Добавил новую программу эфиров"

# Отправить на GitHub
git push
```

### Полезные команды Git:

```bash
# Посмотреть историю коммитов
git log

# Откатить изменения в файле
git checkout -- filename

# Создать новую ветку для экспериментов
git checkout -b feature-name

# Вернуться на главную ветку
git checkout main
```

## Распространённые проблемы

### Проблема: "npm не является командой"

**Решение:** Установите Node.js (см. Шаг 1) и перезапустите терминал/VS Code

### Проблема: "Port 3000 is already in use"

**Решение:** 
- Закройте другое приложение на порту 3000
- Или измените порт в `vite.config.js`:
```javascript
server: {
  port: 3001, // Измените на любой свободный порт
  open: true
}
```

### Проблема: Ошибка при git push

**Решение:**
- Убедитесь что у вас есть права на репозиторий
- Используйте Personal Access Token вместо пароля
- Проверьте правильность URL репозитория: `git remote -v`

### Проблема: Сайт на GitHub Pages не работает

**Решение:**
- Проверьте что Actions успешно завершились (вкладка Actions в GitHub)
- Подождите 2-3 минуты после первого деплоя
- Проверьте что в Settings → Pages выбран "GitHub Actions"
- Очистите кеш браузера (Ctrl+Shift+R)
